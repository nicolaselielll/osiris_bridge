# Security

## Reporting a vulnerability

Please report security problems privately, by email to **nicolas@osirislabs.io**.

It helps to include:

- what you found and what an attacker could do with it,
- the steps to reproduce it,
- the bridge version (`pip show osiris-bridge`), the ROS 2 distribution, and the operating system.

We'll confirm we received your report, keep you updated while we work on a fix, and tell you when it's released. Let us know if you'd like to be credited.

## Supported versions

Fixes go into the latest release on PyPI. To get them, upgrade with `pip install --upgrade osiris-bridge`.

## Scope

This repository holds the Osiris bridge, which runs on the robot and connects it to an Osiris gateway. Problems with an Osiris server, whether hosted or installed on your own machines, can be reported to the same address.
